# augur

Word prediction library in Rust, in the spirit of
[Presage](https://presage.sourceforge.io/): given the text around the cursor,
it suggests the next word or completes the current one. It runs on Windows,
Linux and macOS, and has a C API and a header-only C++17 wrapper.

> Status: phase 0 (scaffolding). The pipeline and C/C++ SDK build and test,
> but no real predictors or models exist yet.

## Layout

| Path | Contents |
|---|---|
| `crates/augur-core` | Traits and types: `Predictor`, `LanguagePack`, `Combiner`, `Suggestion` |
| `crates/augur` | Facade: `Engine` and `EngineBuilder` |
| `crates/augur-capi` | C API; `include/augur.h` is generated by cbindgen at build time |
| `bindings/cpp` | Header-only C++17 wrapper `augur.hpp` |
| `bindings/tests` | C and C++ (Catch2) SDK tests |
| `crates/augur-text`, `-lm`, `-predictors`, `-user`, `-lang-en`, `-train`, `-cli` | Placeholders for later phases |
| `xtask` | Developer tasks |

## Building

Requirements: rustup (the pinned toolchain installs automatically), and for
the C/C++ SDK, CMake 3.22+ and a C/C++ compiler.

```sh
cargo xtask ci          # fmt check, clippy, Rust tests, C header check
cargo xtask sdk         # build and test the C/C++ SDK with CMake
```

If `cmake` is not on your `PATH` (e.g. you use the copy bundled with Visual
Studio), point `CMAKE` at it:

```powershell
$env:CMAKE = "C:\Program Files\Microsoft Visual Studio\18\Community\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin\cmake.exe"
cargo xtask sdk
```

### Using from CMake

```cmake
add_subdirectory(path/to/augur)
target_link_libraries(my_app PRIVATE Augur::augur_cpp)   # or Augur::augur_static / Augur::augur_shared
```

An installable `find_package(Augur)` package is planned for phase 4.
